# ADR 0010: Interface em portugues, moeda Kz e contexto Angola

## Status

Aceita.

## Contexto

O produto e destinado ao contexto operacional de academia em Angola.

## Decisao

Usar textos em portugues, moeda Kz e dados simulados com telefones, documentos e contexto angolano.

## Consequencias

- Valores financeiros devem aparecer em Kz.
- Fluxos devem usar termos locais como BI, NIF, provincia, Luanda e Angola.
- Novas telas devem manter portugues como idioma padrao.
